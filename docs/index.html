SAFE SOJA.

Software e IoT · Em equipe

Monitoramento inteligente da umidade do solo em plantações de soja.

Projeto desenvolvido em grupo na SPTech integrando hardware e software para acompanhar condições hídricas na lavoura e apoiar a tomada de decisão agrícola.

Atuei com foco nas áreas de back-end e engenharia de dados, estruturando a API em Node.js, o tratamento das leituras enviadas pelos sensores Arduino e a persistência no banco de dados MySQL.

  • Coleta contínua de dados via sensores conectados ao Arduino
  • API REST em Node.js e armazenamento estruturado em MySQL
  • Painel web para visualização de métricas e alertas de umidade

SafeSoja · Arquitetura & IoT

Objetivo: Reduzir perdas hídricas e otimizar o cultivo de soja por meio do monitoramento contínuo da umidade do solo.

Fluxo técnico: Sensores capacitivos conectados ao microcontrolador Arduino capturam os níveis de umidade e enviam os dados para uma API desenvolvida em Node.js, que trata as leituras e armazena o histórico no banco relacional MySQL para exibição em dashboard web.

Missão Brasil · Plataforma Full Stack

Objetivo: Criar uma experiência educativa e interativa sobre as Forças Armadas do Brasil unindo conteúdo histórico e gamificação.

Arquitetura: Desenvolvida de ponta a ponta com HTML, CSS e JavaScript no front-end, servidor Node.js com gerenciamento de sessão para login/cadastro e persistência de resultados do quiz e métricas no MySQL.
